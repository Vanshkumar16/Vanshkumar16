# GitHub profile README setup

Copy `README.md` and the `.github/workflows/` folder into the root of
`Vanshkumar16/Vanshkumar16`.

## Enable the 3D contribution graph

1. Open the profile repository's **Settings → Actions → General**.
2. Under **Workflow permissions**, allow read and write permissions.
3. Open **Actions**, select **GitHub Profile 3D Contributions**, and click
   **Run workflow**.
4. After the first successful run, `profile-3d-contrib/profile-night-rainbow.svg`
   will be committed and the README image will display.
5. The workflow refreshes daily at 18:00 UTC.

The workflow follows the official instructions for
[yoshi389111/github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib).

## Enable GitHub metrics (languages, habits, starred repositories)

1. Create a GitHub fine-grained personal access token with read access to public
   profile/repository data and the required account data. For private repository
   information, grant only the additional access you intend to expose.
2. In the profile repository, open **Settings → Secrets and variables → Actions**.
3. Add a repository secret named `METRICS_TOKEN`.
4. Run **GitHub Profile Metrics** from the Actions tab once.
5. The generated `github-metrics.svg` will be committed and refreshed daily.

Do not put a token directly in the README or workflow file. Keep it in GitHub
Actions secrets.

## Contribution streak card

The README still uses the Streak Stats hosted image endpoint. If that third-party
service is unavailable, the card may temporarily fail; the metrics SVG provides
a separate contribution/activity view and is generated by your own workflow.
